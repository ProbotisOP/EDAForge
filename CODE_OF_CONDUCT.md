# Code of conduct

EDAForge adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for every project space and for anyone representing the project.

In short: be respectful, assume good faith, critique ideas rather than people, and remember that
statistics is a field where honest disagreement and correction are normal and welcome.

## Reporting

Report unacceptable behaviour privately to the project maintainers listed in
[GOVERNANCE.md](GOVERNANCE.md). Until a dedicated conduct address is published there, use a
private GitHub security advisory on this repository and mark it "code of conduct". Reports are
handled confidentially, and the enforcement guidelines of the Contributor Covenant apply.
